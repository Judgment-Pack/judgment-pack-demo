# attested/ — the desk's output shelf

Everything else in this directory is generated by `attest` and deliberately
untracked, so `scripts/reset-demo.sh` (`git clean -fd`) clears it:

- `session.json` — the claim of what was asked: session id, subject, template.
  Deliberately NOT the gateway's response body — derivation reads only store
  bytes a verified receipt covers.
- `registry.fetched.jsonl` — the seal registry as fetched from the key holder
  at check time (never read from the store under audit). Kept so the audience
  can inspect the anchor that was actually used.
- `screening-inputs.json` — the derived graph inputs `jpack experimental graph
  evaluate` consumes. Written on every `attest check`: verified runs carry the
  attested matchCount; withheld runs carry `screening-record: unknown`.

The derived inputs do not live in `graphs/` because `graphs/inputs-*.json` are
generated from `vendor-onboarding.rows.json` (see `graphs/README.md`) and
guarded by drift CI; this shelf is runtime output, not fixtures.
